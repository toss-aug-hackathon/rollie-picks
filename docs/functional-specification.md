## F-01 고민·선택지 설정

- 목적: 사용자가 데굴픽에 맡길 질문과 후보를 정합니다.
- Actor: 인증이 필요 없는 앱 사용자
- 사전 조건: 코스와 캐릭터 미리보기가 초기화되어 `mapReady`가 참이어야 합니다.
- 입력: 고민 제목 1~20자, 필수 선택지 2개와 선택 선택지 최대 2개(각 1~12자)
- 정상 흐름:
  1. 고민 제목을 입력합니다.
  2. 앞의 두 선택지를 입력하고 필요하면 세 번째·네 번째 선택지를 추가합니다.
  3. 활성 선택지별 캐릭터를 고릅니다.
  4. 제출 버튼을 눌러 배치 화면으로 이동합니다.
- 예외 흐름:
  - 고민이 비어 있으면 하단 토스트로 입력을 요청합니다.
  - 앞의 두 선택지 중 하나가 비어 있으면 하단 토스트로 입력을 요청합니다.
  - 맵이 준비되지 않았거나 필수 입력이 없으면 제출 버튼이 비활성화됩니다.
- 출력/완료 조건: 참가자 정보가 엔진에 전달되고 레이스가 초기화된 뒤 배치 상태로 전환됩니다.
- 권한·데이터: 인증과 인가가 없으며 입력은 메모리에만 유지됩니다.

## F-02 캐릭터·출발 위치 설정

- 목적: 선택지별 외형과 레이스 시작 위치를 정합니다.
- 입력: 10종 캐릭터 중 하나, 포인터로 지정한 시작 좌표
- 정상 흐름:
  1. 이전/다음 버튼으로 활성 선택지의 캐릭터를 변경합니다.
  2. 배치 화면에서 캐릭터를 누르고 허용 영역 안으로 끕니다.
  3. 포인터를 놓으면 캐릭터가 해당 위치에 정착합니다.
  4. `데굴이 출발`을 눌러 카운트다운을 시작합니다.
- 예외 흐름:
  - 다른 활성 선택지가 사용 중인 캐릭터는 선택 후보에서 제외됩니다.
  - 비활성인 세 번째·네 번째 선택지의 캐릭터 컨트롤은 비활성화됩니다.
  - 배치 위치가 다른 캐릭터와 겹치면 엔진이 가장 가까운 빈 가로 위치를 탐색하고, 없으면 원래 위치로 복귀합니다.
- 출력/완료 조건: 활성 캐릭터가 배치된 좌표에서 준비 상태가 됩니다.

## F-03 물리 레이스 진행

- 목적: 캐릭터의 코스 진행 결과로 하나의 선택지를 결정합니다.
- 사전 조건: 엔진 초기화와 배치가 끝나야 합니다.
- 정상 흐름:
  1. 3초 카운트다운 뒤 레이스가 시작됩니다.
  2. Rapier 월드가 고정 timestep으로 갱신되고 Three.js 장면이 렌더링됩니다.
  3. HUD가 경과 시간, 상태, 진행률과 실시간 순위를 갱신합니다.
  4. 첫 캐릭터가 결승선을 통과하면 현재 위치 기준 전체 순위를 계산합니다.
  5. 800ms 뒤 결과 화면으로 전환합니다.
- 게임 규칙:
  - 캐릭터는 부착 패드를 번갈아 사용해 회전하며 내려갑니다.
  - 낮 테마에는 두더지, 밤 테마에는 유령 장애물이 등장하고 바위·물 구간이 속도와 움직임에 영향을 줍니다.
  - 선두와 후미 간격이 커지면 후미 캐릭터에 추격 보정을 적용합니다.
  - 40초 이후 속도를 높이고 58초에 도달하면 현재 선두를 우승자로 확정합니다.
- 예외 흐름:
  - Rapier 또는 테마 텍스처 초기화에 실패하면 오류 화면과 `다시 시도` 버튼을 표시합니다.
  - 문서가 숨겨지면 오디오를 중단하고 다시 보일 때 가능한 경우 재개합니다.
- 출력/완료 조건: 우승 선택지, 우승 캐릭터, 결과 문구와 전체 순위를 생성합니다.

## F-04 레이스 일시정지

- 목적: 진행 중인 레이스를 멈추고 계속·재시작·종료 중 하나를 선택합니다.
- 정상 흐름: HUD 메뉴 버튼으로 일시정지 모달을 열고 `계속하기`, `다시하기`, `그만하기` 중 하나를 선택합니다.
- 결과:
  - 계속하기: 경과 시간 기준점을 보정하고 레이스와 오디오를 재개합니다.
  - 다시하기: 레이스 상태를 초기화하고 배치 화면으로 돌아갑니다.
  - 그만하기: 레이스를 초기화하고 설정 화면으로 돌아갑니다.
- 예외 흐름: 이미 결과가 확정된 상태에서는 엔진의 일시정지 요청을 무시합니다.

## F-05 결과 확인과 재시도

- 목적: 선택된 답과 전체 순위를 확인하고 다음 행동을 정합니다.
- 정상 흐름:
  1. 우승 선택지, 우승 캐릭터, 응원 문구와 활성 선택지 전체 순위를 표시합니다.
  2. `선택지 변경`을 누르면 설정 화면으로 돌아갑니다.
  3. `다시 골라줘`를 누르면 두 단계 확인을 거쳐 같은 선택지로 배치 화면에 돌아갑니다.
- 예외 흐름: 캐릭터 미리보기 이미지가 없으면 순위 목록에서 이모지로 대체합니다.
- 제한: 결과 저장, 이미지 생성, OS 공유 기능은 구현되어 있지 않습니다.

## F-06 소리·진동·테마 설정 저장

- 목적: 사용자의 비게임 설정을 다음 실행에도 유지합니다.
- 입력: 소리 여부, 진동 여부, `day`·`night`·`auto` 테마
- 정상 흐름:
  1. 앱 시작 시 익명 키와 저장 설정을 병렬로 읽습니다.
  2. 유효한 설정만 React 상태에 반영합니다.
  3. 설정 변경 후 300ms가 지나면 앱인토스 `Storage`에 JSON으로 저장합니다.
  4. 자동 테마는 현지 시각 19:00~05:59를 밤으로 판단합니다.
- 예외 흐름:
  - 익명 키나 저장소 접근 실패는 앱 사용을 막지 않습니다.
  - 손상된 JSON과 알 수 없는 테마 값은 무시하고 안전한 기본값을 사용합니다.
  - 햅틱 API가 실패하면 가능한 브라우저에서 `navigator.vibrate`를 사용합니다.
- 저장 데이터: 소리, 진동, 테마 설정과 익명 키 해시. 비밀 값이나 사용자 입력·결과는 저장하지 않습니다.

## 미구현·확인 필요

- 결과 공유와 이미지 저장은 기존 README의 계획에만 있었고 현재 실행 경로에는 없습니다.
- 앱인토스 WebView의 실제 햅틱, 화면 켜짐 유지, iOS 스와이프 제어는 기기 환경에서 확인이 필요합니다.
- 자동화된 기능 테스트가 없어 정상·예외 흐름은 코드 연결과 프로덕션 빌드로만 검증되었습니다.
