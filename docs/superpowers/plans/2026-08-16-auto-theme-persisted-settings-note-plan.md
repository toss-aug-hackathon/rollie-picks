# 자동 테마 기본값 및 설정 저장 안내 구현 계획

## 1. 기본 상태 변경

- `src/App.tsx`의 신규 사용자 `themeMode` 초기값을 `auto`로 변경한다.
- `src/game/engine.ts`의 내부 기본값도 `auto`로 맞춘다.
- 기존 Storage 읽기·쓰기 키, 검증, 300ms 지연 저장 로직은 변경하지 않는다.

## 2. 저장 안내 문구 추가

- `src/components/SetupScreen.tsx`의 설정 행 바로 아래에 `소리·진동·배경 설정은 다음에도 유지돼요.`를 추가한다.
- 전용 `settings-note` 클래스를 사용해 설정 전체에 대한 보조 설명임을 분명히 한다.

## 3. 고정 화면 스타일 적용

- `index.html`에서 설정 행 아래 여백을 안내 문구 공간으로 재배분한다.
- 안내 문구를 10px, 조밀한 행간, 한 줄 표시로 구성한다.
- 밤 테마용 대비 색상과 700px 이하 화면용 축소 여백을 추가한다.
- overflow, 스크롤뷰, 내부 스크롤 컨테이너는 추가하지 않는다.

## 4. 정적 및 빌드 검증

- `git diff --check`
- `npm exec tsc -- --noEmit`
- `npm run build`
- `npm run build:ait`

## 5. 화면 및 상태 검증

- 저장값이 없는 상태에서 자동 모드가 선택되는지 확인한다.
- 소리, 진동, 배경 선택을 바꾼 뒤 저장 객체에 세 값이 반영되는지 확인한다.
- 일반 화면과 높이 700px 이하 화면에서 안내 문구가 한 줄이고 문서 세로 스크롤이 없는지 확인한다.
- 낮과 밤 테마에서 문구 대비와 CTA 노출을 확인한다.
- 배치와 게임 시작 흐름에 회귀가 없는지 확인한다.
