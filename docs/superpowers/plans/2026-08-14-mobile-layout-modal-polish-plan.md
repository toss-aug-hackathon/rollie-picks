# 모바일 홈·모달·종료선 개선 구현 계획

## 1. 토스 네비게이션 기본값

- `granite.config.ts`에서 명시적인 `navigationBar` 블록을 제거한다.
- `webViewProps.type: 'partner'`와 제스처·오버스크롤 설정은 유지한다.
- AIT 빌드 산출물에서 비게임 타입이 유지되는지 확인한다.

## 2. 홈 화면 세로 리듬

- `index.html`의 홈 헤더 간격과 제목 줄 높이를 조정한다.
- 짧은 화면에서 캐릭터 선택 카드와 캐릭터 이미지를 소폭 확대한다.
- 캐릭터 이름 배지 아래에 여백을 확보한다.
- 390×700 뷰포트에서 문서 및 홈 화면 스크롤이 생기지 않는지 확인한다.

## 3. 결과 및 재선택 모달

- 결과 카드와 재선택 카드에 동일한 반응형 높이 규칙을 적용한다.
- 결과 카드의 캐릭터, 피드백, 순위 목록, 버튼 간격을 압축한다.
- 재선택 캐릭터 더미와 개별 이미지를 축소한다.
- 재선택 버튼 영역을 카드 내부 하단에 유지하고 하단 패딩을 확보한다.
- 참가자 2명/4명 및 최종 확인 상태에서 잘림과 접근성을 확인한다.

## 4. 종료선 패턴

- `src/game/course.ts`에 짝수 열의 2행 체크 패턴 캔버스를 생성한다.
- 기존 이미지 반복 텍스처를 캔버스 텍스처로 교체한다.
- 코스보다 약간 넓은 평면에 적용해 좌우 빈틈을 제거한다.

## 5. 검증 및 커밋

- `git diff --check`
- `npm run build`
- `npm run build:ait`
- 인앱 Browser로 홈, 게임 종료선, 결과 모달, 재선택 모달을 모바일 뷰포트에서 검증한다.
- 관련 변경만 논리 단위로 커밋하고 작업 트리가 깨끗한지 확인한다.
