# 모바일 컨트롤·모달 밀도 개선 구현 계획

## 1. 홈 컨트롤과 HUD

- `index.html`에서 캐릭터 좌우 선택 버튼의 터치 영역과 아이콘 크기를 확대한다.
- 설정 컨트롤 그룹의 너비, 행 높이, 수직 정렬을 통일하고 화면 중앙에 배치한다.
- HUD와 제목 행의 최소 너비 및 오버플로 경계를 고정한다.
- `HUD.tsx`의 긴 제목 크기 계산과 말줄임 동작을 확인한다.

## 2. 결과 및 재선택 모달

- 결과와 재선택 카드의 공통 높이를 460px 이하로 낮춘다.
- 결과 캐릭터, 순위 캐릭터, 피드백과 목록 간격을 줄인다.
- 재선택 캐릭터 최대 크기와 배치 간격을 줄인다.
- 최종 확인 캐릭터를 중앙으로 모은다.
- 재선택 버튼에 한정해 눌림 이동과 그림자 축소를 제거한다.

## 3. 일시정지 모달

- `PauseModal.tsx`의 최대 너비, 패딩, 제목과 설명 간격을 줄인다.
- TDS 버튼 스타일은 유지하고 버튼 높이와 버튼 사이 간격만 축소한다.

## 4. 검증

- `git diff --check`
- `npm run build`
- `npm run build:ait`
- 390×700 모바일 화면에서 홈 무스크롤과 설정 중앙 정렬 확인
- 최대 길이 고민 제목에서 HUD 및 햄버거 위치 확인
- 결과, 재선택, 최종 확인, 일시정지 모달 크기와 잘림 확인
- 재선택 버튼 누름 상태의 스타일 유지 확인

## 5. 커밋

- 홈 및 HUD 안정화 변경 커밋
- 결과·재선택·일시정지 모달 밀도 변경 커밋
- 작업 트리와 최종 커밋 로그 확인
