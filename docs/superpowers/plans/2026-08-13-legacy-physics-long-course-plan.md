# 원본 물리엔진 및 긴 코스 이식 구현 계획

1. 새 낮·밤 PNG를 배경 자산으로 추가하고 코스 높이 2800, 결승 좌표 2350, 강 좌표 1350~1780을 복원한다.
2. `GameEngine`의 캐릭터 타입과 시각 모델을 원본의 곰·토끼·고양이·오리·거북이로 복원한다.
3. 원본의 파트별 콜라이더, 강체 설정, 패드 상태 전이, 배치 충돌 회피, 정체 복구를 클래스 구조에 이식한다.
4. 원본의 물 감속, 추격·흔들기 가속, 장애물 상태 기계, 충돌 넉백, 가장자리 복귀 힘과 60Hz 처리 순서를 이식한다.
5. 선택 화면에서 유령·두더지를 제거하고 거북이를 추가한다.
6. 원본 핵심 상수와 계산식을 정적으로 대조하고 Vite 빌드 및 브라우저 실행을 검증한다.
