# 자동 테마 기본값 및 설정 저장 안내 설계

## 목표

- 저장된 설정이 없는 신규 사용자의 배경 모드를 `자동(시간대)`으로 시작한다.
- 사용자가 선택한 소리, 진동, 배경 모드는 기존 Apps in Toss Storage에 계속 저장하고 다음 실행에서 복원한다.
- 설정이 유지된다는 사실을 홈 화면에서 짧게 안내한다.
- 작은 화면에서도 스크롤뷰를 추가하지 않고 현재 고정형 홈 화면을 유지한다.

## 확인된 현재 상태

- `App`의 신규 사용자 테마 기본값과 `GameEngine`의 내부 기본값은 `day`다.
- `App`은 Storage 준비 후 `soundEnabled`, `hapticEnabled`, `themeMode`를 읽어 유효한 저장값이 있으면 기본값을 덮어쓴다.
- 같은 세 값은 변경 후 300ms 지연을 두고 Storage에 다시 저장된다.
- 설정 행은 소리, 진동, 배경 선택을 한 줄에 표시하며 CTA 위의 세로 공간이 제한적이다.
- 짧은 화면 전용 미디어 쿼리가 설정 행과 CTA 여백을 이미 축소한다.

## 선택한 접근법

설정 행 아래에 다음 단일 안내 문구를 10px 크기로 표시한다.

> 소리·진동·배경 설정은 다음에도 유지돼요.

설정 행의 기존 아래 여백 일부를 안내 문구 공간으로 전환해 화면 전체 높이 증가는 최소화한다. 안내 문구는 별도의 박스, 아이콘, 툴팁 없이 한 줄 텍스트로만 제공한다.

## 상태 및 저장 흐름

1. 앱이 시작되면 `themeMode`를 `auto`로 초기화한다.
2. Storage에 이전 설정이 있으면 저장된 소리, 진동, 배경 모드를 복원한다.
3. 저장된 테마가 없거나 값이 손상된 신규 상태에서는 `auto`를 유지한다.
4. 사용자가 설정을 변경하면 현재 300ms 지연 저장 로직이 세 설정을 함께 저장한다.
5. 다음 실행에서는 저장된 사용자 선택이 `auto` 기본값보다 우선한다.

기존 사용자가 이미 `day` 또는 `night`를 저장한 경우 해당 선택은 변경하지 않는다. 자동 기본값은 저장값이 없는 신규 사용자와 손상된 저장값의 안전한 초기 상태에만 적용된다.

## 코드 변경

### 기본값 일치

- `src/App.tsx`의 `themeMode` 초기값을 `auto`로 변경한다.
- `src/game/engine.ts`의 내부 `themeMode` 초기값도 `auto`로 변경해 App 외부 초기화 경로에서도 동작을 일치시킨다.
- 시간대 판정 기준과 낮·밤 배경 선택 로직은 변경하지 않는다.

### 안내 문구

- `src/components/SetupScreen.tsx`에서 설정 행 바로 다음에 안내 문구를 추가한다.
- 안내 문구는 설정 행 전체를 설명하므로 배경 선택 요소 안이나 특정 토글 라벨 안에 넣지 않는다.
- 보조 설명임을 나타내는 전용 클래스와 일반 텍스트 요소를 사용한다.

### 고정 화면 레이아웃

- `index.html`의 설정 행 아래 여백을 줄이고 안내 문구에 작은 글꼴과 조밀한 행간을 적용한다.
- 기본 화면과 700px 이하 짧은 화면에서 안내 문구가 한 줄을 유지하도록 한다.
- 밤 테마에서는 배경 대비를 확보하는 별도 글자색을 적용한다.
- `overflow`, 스크롤 컨테이너, 화면 내부 스크롤뷰는 추가하지 않는다.
- CTA 위치와 safe-area 하단 패딩은 유지한다.

## 오류 및 접근성

- Storage 읽기나 쓰기가 실패해도 현재처럼 앱 사용을 막지 않는다.
- 손상된 저장값은 무시하고 `auto` 기본값을 사용한다.
- 안내 문구는 상호작용 요소가 아니므로 포커스 순서에 포함하지 않는다.
- 글자가 너무 흐려지지 않도록 낮과 밤 테마 모두에서 충분한 대비를 유지한다.

## 검증 계획

- `npm exec tsc -- --noEmit`으로 타입 검사를 실행한다.
- `npm run build`와 `npm run build:ait`가 성공하는지 확인한다.
- 저장값이 없는 상태에서 자동 모드가 선택되는지 확인한다.
- 낮과 밤 시간대 판정이 기존 기준대로 배경에 반영되는지 확인한다.
- 소리, 진동, 배경 설정 변경 후 Storage 저장 객체에 세 값이 모두 유지되는지 코드와 런타임에서 확인한다.
- 일반 높이와 700px 이하 화면에서 안내 문구가 한 줄로 보이고 CTA가 잘리거나 화면 스크롤이 생기지 않는지 확인한다.
- 낮·밤 테마에서 안내 문구 가독성을 확인한다.

## 완료 기준

- 신규 사용자의 기본 배경 모드가 `자동(시간대)`이다.
- 기존 사용자의 저장된 설정은 그대로 복원된다.
- `소리·진동·배경 설정은 다음에도 유지돼요.` 문구가 설정 행 아래에 한 줄로 표시된다.
- 작은 화면에서도 홈 화면에 스크롤뷰나 세로 스크롤이 추가되지 않는다.
- 기존 설정, 게임 시작, 배치와 레이스 흐름에 회귀가 없다.

## 범위 밖

- Storage 키 또는 저장 데이터 스키마 변경
- 기존 사용자 설정의 강제 초기화
- 시간대 경계값 변경
- 시스템 다크 모드와 Toss `ColorSchemeArea` 연동
- 설정 화면의 전체 레이아웃 재설계
- 스크롤뷰 또는 내부 스크롤 컨테이너 도입
