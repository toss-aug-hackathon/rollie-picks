# 결과 마키 및 야간 테마 UI 수정 설계

## 목표

결과 화면의 반복 문구가 다시 오른쪽에서 왼쪽으로 흐르게 하고, 야간 테마에서 토스트 문구와 시작 버튼의 가독성 및 색상 일관성을 복원한다.

## 변경 범위

- `.story-marquee-track`에 CSS 기반 무한 좌측 이동 애니메이션을 적용한다.
- 트랙에 이미 존재하는 두 세트의 반복 문구를 사용해 이동이 끊기지 않게 한다.
- 야간 `.setup-toast`는 밝은 배경과 대비되는 진한 글자색 및 테두리를 명시한다.
- 야간 `#setup-submit`은 일반 `.primary`보다 구체적인 선택자로 보라색 배경, 흰색 글자, 보라색 테두리를 적용한다.
- 야간 시작 버튼의 `is-incomplete` 상태도 보라색을 유지한다. 입력 검증은 제출 시 토스트로 안내하는 현재 동작을 유지한다.

## 접근법

React나 GSAP 생명주기를 추가하지 않고 `index.html`의 CSS만 수정한다. 결과 오버레이가 조건부 렌더링되더라도 CSS 애니메이션은 요소가 나타날 때 자동 시작되므로 안정적이다.

## 접근성 및 검증

- `prefers-reduced-motion: reduce`에서는 기존 전역 정책에 따라 애니메이션이 사실상 정지한다.
- 프로덕션 빌드를 통과시킨다.
- 브라우저에서 결과 마키의 위치가 시간에 따라 감소하는지 확인한다.
- 야간 테마에서 토스트의 계산된 글자색과 시작 버튼의 계산된 배경색을 확인하고 스크린샷으로 검증한다.

## 제외 범위

- 결과 화면 구조 변경
- 토스트 메시지 내용 변경
- 게임 엔진 및 물리 계산 변경
