# 메인 화면 샘플 디자인 프로토타입

## 목적

`C:\Users\admin\Downloads\deguri_sample.html`의 시각 언어를 현재 게임의 시작 화면에 빠르게 적용한다. 사용자는 실제 화면을 확인한 뒤 같은 디자인을 레이스와 결과 화면까지 확장할지 판단한다.

## 작업 범위

- `#setup` 시작 화면만 변경한다.
- 질문 입력, 2×2 선택지/캐릭터 카드, 소리·진동 설정, 시작 버튼을 샘플 구조에 맞춘다.
- 기존 캐릭터 PNG와 캐릭터 순환 선택 기능을 유지한다.
- 기존 폼 검증과 레이스 시작 동작을 유지한다.
- 모바일 360~430px 너비에서 사용할 수 있게 만든다.

## 제외 범위

- Three.js/Rapier 레이스 장면과 물리 로직
- 레이스 HUD와 안내 버튼
- 카운트다운 화면
- 결과 화면
- 캐릭터 및 배경 이미지 교체
- 새로운 기능이나 외부 UI 라이브러리 추가

## 시각 디자인

샘플의 네오브루탈 디자인을 시작 화면에만 적용한다.

- 배경: 따뜻한 크림 `#FFF9E6`
- 핵심색: 오렌지 `#F97316`
- 보조색: 캐릭터 카드별 연한 노랑, 로즈, 인디고, 스카이
- 주요 입력과 카드: 2~3px 검정 외곽선
- 그림자: 2px 또는 4px 검정 하드 섀도
- 모서리: 입력 16px, 카드 16px, 주요 버튼 24px
- 본문 서체: `Noto Sans KR`
- 장식 서체: `Gaegu`
- 버튼 피드백: 누르면 아래로 이동하고 하드 섀도가 사라진다.

## 화면 구성

시작 화면은 위에서 아래로 다음 순서를 사용한다.

1. 얇은 오렌지 상단 바
2. `D E G U L - I` 브랜드 배지
3. 제목과 한 줄 설명
4. 라벨이 겹쳐진 질문 입력
5. 2×2 선택지/캐릭터 카드
6. 소리·진동 체크박스
7. 전체 너비 오렌지 시작 버튼
8. 작은 엔진 표기

각 캐릭터 카드는 이름 입력, 좌우 선택 버튼, 기존 캐릭터 PNG, 캐릭터명 배지를 포함한다. 빈 선택지는 기존 동작과 동일하게 선택 참가자에서 제외된다.

## 구현 경계

- 기존 DOM ID와 폼 필드 이름을 가능한 한 유지해 `code/game.js`와의 연결을 보존한다.
- 변경 스타일은 `#setup` 또는 `.setup-page` 아래로 한정해 나머지 화면에 영향을 주지 않는다.
- 샘플의 인라인 Tailwind 결과물을 그대로 복사하지 않고, 필요한 규칙만 일반 CSS로 정리한다.
- Phosphor Icons는 추가하지 않는다. 화살표는 텍스트 또는 CSS로 표현한다.
- 게임 로직 변경은 새 마크업과 기존 이벤트 연결에 필요한 최소 범위로 제한한다.

## 반응형 및 접근성

- 360~430px 너비에서 가로 스크롤이 생기지 않아야 한다.
- 세로 공간이 부족한 기기에서는 시작 화면 내부가 자연스럽게 스크롤되어야 한다.
- 터치 컨트롤은 최소 44px 영역을 확보한다.
- 키보드 포커스가 명확히 보여야 한다.
- `prefers-reduced-motion` 설정을 존중한다.
- 라벨과 `aria-label`을 유지한다.

## 검증 기준

- 360×800, 390×844, 430×932에서 시작 화면이 깨지지 않는다.
- 질문과 필수 선택지 두 개를 입력하면 시작 버튼이 활성화된다.
- 캐릭터 좌우 선택과 중복 방지 동작이 유지된다.
- 소리와 진동 설정이 레이스 시작 시 반영된다.
- 시작 버튼을 누르면 기존 레이스가 정상적으로 시작된다.
- 레이스와 결과 화면의 기존 디자인 및 기능에 회귀가 없다.
- `npm run build`가 성공한다.
- 브라우저 콘솔에 새 오류가 없다.
