# 원본 물리엔진 및 긴 코스 이식 설계

## 목표

React로 마이그레이션되기 전 `/Users/ldy/Desktop/game.ts`, `/Users/ldy/Desktop/course.ts`, `/Users/ldy/Desktop/index.html`을 기준으로 레이서 물리와 장애물 동작을 현재 React 애플리케이션에 복원한다. 새 낮·밤 코스 이미지 전체를 높이 2800의 게임 코스로 표시하여 현재 코스보다 오래 내려오게 한다.

## 기준과 불변 조건

- 레이서 물리의 기준 구현은 `/Users/ldy/Desktop/game.ts`이다.
- 물리 상수, Rapier 강체·콜라이더 설정, 그립 패드 상태 전이, 회전과 착지 조건, 충돌 반응, 추격 보정, 정체 복구, 흔들기 가속, 프레임 업데이트 순서를 변경하지 않는다.
- 현재 클래스 구조에 넣기 위한 `this` 참조, 타입 선언, React 콜백 연결만 조정한다.
- 원본 코드와 사용자의 설명이 다를 때는 승인된 결정에 따라 원본 코드를 우선한다. 따라서 밤의 유령은 다리 구간에 한정하지 않고 현재 카메라 구간에서 원본 방식으로 비행한다.
- 선택 가능한 레이서는 곰, 토끼, 고양이, 오리, 거북이다. 두더지와 유령은 선택 캐릭터가 아니라 장애물이다.

## 코스와 좌표계

- `COURSE_HEIGHT`는 원본 값 `2800`으로 복원한다.
- `FLOOR_Y`는 원본 값 `2350`으로 복원한다.
- 시작선과 출발 위치는 원본의 `START_LINE_Y = 360`, `START_Y = 305`를 유지한다.
- 강 판정은 원본의 `RIVER_TOP_Y = 1350`, `RIVER_BOTTOM_Y = 1780`, `BRIDGE_HALF_WIDTH = 64`를 유지한다.
- `/Users/ldy/Desktop/rolling-course-long.png`와 `/Users/ldy/Desktop/rolling-course-night-long.png`를 프로젝트 배경 자산으로 이식하고, 게임 월 전체 `390 × 2800`에 표시한다.
- 이미지가 가진 장식과 물리 판정은 별개다. 물·다리 판정은 이미지 분석이 아니라 원본 상수를 사용한다.
- 시작선과 진행 표시는 현재 React UI를 유지하되, Three.js 코스 마커는 원본 좌표 위에 표시한다.

## 레이서 물리 이식

다음 영역을 함수 단위로 원본과 대조하여 복원한다.

- 신체 파트별 콜라이더 생성과 질량·마찰·반발 계수
- 강체 감쇠, CCD, 추가 솔버 반복 횟수
- 네 개 그립 패드의 생성·해제·재부착
- 회전 시작축, 회전량 계산, 다음 착지 패드 선택
- 첫 패드 해제, 뒤집기 시작, 착지 완료의 조건과 순서
- 레이서 충돌 시 그립 진행 보정
- 장애물 충돌 시 패드 해제, 넉백, 표정, 진동·효과음
- 화면 가장자리 복귀 힘
- 선두와 후발 레이서 사이의 추격 보정
- 정체된 레이서 복구
- 기기 흔들기 가속
- 고정 60Hz Rapier 스텝과 렌더 프레임의 실행 순서

현재 UI에 필요한 참가자 이름, 활성 슬롯, 타이머·진행률·결과 콜백은 물리 계산 바깥에서 연결한다.

## 지형 및 장애물 동작

- 물 구간은 강 세로 범위 안이면서 다리 폭 바깥인 영역이다.
- 물 위에서는 원본과 동일하게 회전 속도에 `WATER_SPEED = 0.72`를 적용한다.
- 낮에는 두더지가 강 구간을 피해 풀숲에 출현한다.
- 두더지는 경고, 등장, 숨김 상태와 원본 타이밍을 유지한다.
- 밤에는 유령이 화면 좌우 바깥에서 진입하여 원본 속도와 비행 시간으로 왕복한다.
- 두 장애물은 같은 물리 객체와 충돌 이벤트 경로를 테마에 따라 전환해 사용한다.

## 현재 React 구조와의 연결

- `src/game/engine.ts`: 원본 물리와 장애물 상태 기계를 보유한다.
- `src/game/course.ts`: 새 낮·밤 이미지 텍스처와 코스 마커를 생성한다.
- `src/components/SetupScreen.tsx`: 다섯 레이서 선택지를 제공한다.
- `src/App.tsx`, `src/components/GameCanvas.tsx`: 기존 React 상태와 엔진 생명주기 연결을 유지한다.
- 장애물 이미지 자산은 기존 `src/assets/obstacles` 파일을 재사용한다.

## 오류 처리와 자원 정리

- 엔진 초기화 실패는 현재 오류 UI 흐름으로 전달한다.
- 텍스처 로딩은 Vite의 정적 자산 URL을 사용한다.
- 컴포넌트 해제 시 애니메이션 프레임, 포인터 이벤트, Three.js 및 Rapier 자원을 현재 `dispose` 경로에서 정리한다.
- 물리 복원 과정에서 오류를 숨기기 위한 임의 보정 로직을 추가하지 않는다.

## 검증

- TypeScript 및 Vite 프로덕션 빌드를 통과시킨다.
- 원본과 현재 구현의 핵심 상수 및 물리 함수에 대한 정적 대조를 수행한다.
- 낮·밤 코스가 각각 높이 2800으로 표시되는지 확인한다.
- 물 바깥과 물 위에서 동일 레이서의 회전 속도 차이를 확인한다.
- 낮 두더지가 강 구간에 생성되지 않는지 확인한다.
- 밤 유령이 좌우로 비행하고 충돌 넉백을 발생시키는지 확인한다.
- 다섯 레이서 선택과 결과 화면 이미지가 정상 동작하는지 확인한다.
- 2명과 4명 경기, 재시작, 테마 변경을 회귀 검증한다.

- 유령을 다리 구간으로 제한하는 신규 규칙
- 화면 디자인의 추가 개편
