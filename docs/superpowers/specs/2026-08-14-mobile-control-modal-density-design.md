# 모바일 컨트롤·모달 밀도 개선 설계

## 목표

실제 iPhone 토스 WebView에서 확인된 홈 컨트롤 정렬, 긴 고민 제목의 HUD 밀림, 버튼 눌림 상태의 시각적 왜곡을 해결한다. 결과, 재선택, 일시정지 모달은 콘텐츠를 유지하면서 더 작고 안정적인 크기로 줄인다.

## 범위

- 홈 캐릭터 좌우 선택 버튼 확대
- 소리, 진동, 테마 선택기 중앙 정렬
- 긴 고민 제목에 대한 HUD 너비 제한과 말줄임
- 재선택 모달 버튼 눌림 스타일 고정
- 결과와 재선택 모달 공통 높이 추가 축소
- 결과 및 재선택 캐릭터 이미지 축소와 간격 조정
- 일시정지 모달 크기와 내부 여백 축소

게임 물리, 참가자 입력 규칙, 음향, 토스 네비게이션 설정은 변경하지 않는다.

## 홈 컨트롤

캐릭터 좌우 선택 버튼은 현재보다 터치 영역과 화살표를 약 4px 키운다. 캐릭터 이미지와 카드 높이는 유지해 홈 화면 무스크롤 조건을 보존한다.

소리, 진동, 테마 선택기는 하나의 중앙 정렬 그룹으로 취급한다. 세 컨트롤의 높이와 수직 중심을 맞추고, 그룹 너비를 콘텐츠에 맞게 제한한 뒤 화면 가운데에 배치한다. 짧은 화면에서도 동일한 정렬을 유지한다.

## 긴 고민 제목 HUD

HUD와 제목 행에 `min-width: 0`, 명시적 가로 경계, `overflow: hidden`을 적용한다. 고민 제목은 햄버거 버튼이 차지하는 공간을 제외한 너비 안에서만 렌더링하고 말줄임표로 끝낸다. 제목 길이는 HUD, 햄버거 버튼, 진행률 배지의 위치나 전체 화면 가로 폭을 변경하지 않는다.

## 재선택 버튼 눌림 상태

공통 `.primary`와 `.secondary` 버튼의 눌림 효과는 다른 화면에서 유지한다. 재선택 모달 내부의 `그래, 한 번 더!`, `응, 진짜!`, `잠깐 쉴게` 버튼에만 별도 `:active` 규칙을 적용해 이동과 그림자 축소를 제거한다. 누르고 있는 동안에도 평상시와 동일한 폰트, 위치, 테두리, 그림자를 유지한다.

## 결과 및 재선택 모달

두 모달은 동일한 공통 외곽 높이를 사용한다. 일반 모바일 화면의 최대 높이는 460px 이하, 짧은 화면은 약 430px을 목표로 한다. 참가자 수가 많아 내용이 넘치는 결과 모달만 내부 스크롤을 허용한다.

결과 모달은 우승 캐릭터, 순위 캐릭터, 피드백 영역과 각 구역 사이 여백을 추가로 줄인다. 제목과 선택 결과의 가독성은 유지한다.

재선택 모달은 제목, 캐릭터 더미, 버튼의 3단 구조를 유지하되 캐릭터 최대 크기를 줄인다. 첫 확인 화면의 지친 캐릭터는 겹침을 유지하면서 더 작게 보이고, `진짜?` 화면의 우는 캐릭터는 좌우 간격을 줄여 중앙에 모은다. 버튼 아래 안전 여백은 유지한다.

## 일시정지 모달

TDS `Modal` 구조는 유지한다. 콘텐츠 최대 너비와 좌우 여백, 상하 패딩, 제목·설명 간격, 버튼 사이 간격을 줄인다. 버튼은 TDS 스타일을 유지하면서 높이만 축소해 전체 모달이 현재보다 짧고 좁게 보이도록 한다.

## 검증

- `npm run build`
- `npm run build:ait`
- 긴 고민 제목에서 HUD가 화면 밖으로 늘어나지 않고 햄버거 버튼이 고정되는지 확인
- 390px 너비의 짧은 모바일 뷰포트에서 홈 무스크롤 확인
- 세 설정 컨트롤의 수평·수직 중앙 정렬 확인
- 재선택 모달 버튼을 누르고 있는 동안 위치와 그림자가 변하지 않는지 확인
- 결과/재선택 모달의 외곽 높이가 같고 목표 높이 이하인지 확인
- `진짜?` 화면의 캐릭터 사이 간격과 하단 버튼 비잘림 확인
- 일시정지 모달의 축소된 외곽 크기와 세 버튼 접근성 확인
- 참가자 2명과 4명 결과 콘텐츠 접근 가능 여부 확인

## 제외 범위

- 버튼 문구와 재선택 확인 단계 변경
- TDS Modal을 별도 커스텀 모달로 교체
- 홈 캐릭터 이미지 및 카드 높이 재조정
- 토스 네이티브 네비게이션 높이 변경
