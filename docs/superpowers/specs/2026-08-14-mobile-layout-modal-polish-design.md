# 모바일 홈·모달·종료선 개선 설계

## 목표

토스 비게임 앱의 기본 네비게이션 구성을 유지하면서 홈 화면의 답답한 간격과 작은 캐릭터를 개선한다. 결과 모달과 다시 골라줘 모달은 더 낮고 동일한 높이로 맞추며, 버튼 잘림과 과도하게 큰 캐릭터 이미지를 해결한다. 게임 종료선은 동일한 색 칸이 맞닿지 않는 정확한 체크 패턴으로 화면 너비를 채운다.

## 범위

- 토스 네이티브 네비게이션을 프레임워크 기본 설정에 맡긴다.
- 홈 헤더와 캐릭터 선택 카드의 세로 리듬을 조정한다.
- 결과 및 다시 골라줘 모달의 공통 높이와 내부 밀도를 줄인다.
- 다시 골라줘 모달의 캐릭터와 버튼 배치를 조정한다.
- 종료선 텍스처 생성 방식을 수정한다.
- 기존 비게임 타입, 화면 스와이프 차단, 음향 및 게임 동작은 유지한다.

## 네비게이션

`granite.config.ts`의 `navigationBar` 블록을 제거한다. 현재 설치된 Apps in Toss 프레임워크의 기본값은 `withBackButton: true`, `withHomeButton: false`이므로 화면 구성은 유지하면서 네이티브 기본값을 직접 사용한다. 비게임 화면을 활성화하는 `webViewProps.type: 'partner'`는 유지한다.

네비게이션 바의 실제 높이는 토스 네이티브 컨테이너가 결정하며 웹 CSS에서 변경하지 않는다. 따라서 앱 콘텐츠에 임의 상단 여백이나 네비게이션 높이 보정값을 추가하지 않는다.

## 홈 화면

짧은 화면용 미디어 쿼리에서도 현재보다 캐릭터 이미지를 약 8px 키운다. 카드 전체 높이는 필요한 만큼만 늘리고 기존 무스크롤 구조를 유지한다. 동물 이름 배지와 카드 하단 사이에는 4~6px의 시각적 여백을 둔다.

상단 띠와 `데굴데굴` 배지 사이, 배지와 제목 사이, 제목의 두 줄 사이, 제목과 설명 사이 간격을 각각 소폭 늘린다. 화면 전체를 다시 늘리지 않고 헤더 내부 여백을 재분배해 답답함만 해소한다.

## 결과 모달과 다시 골라줘 모달

두 상태는 동일한 공통 카드 높이를 사용한다. 목표 높이는 일반 모바일 화면에서 최대 540px이며, 화면이 짧으면 사용 가능한 높이 안에서 자동으로 줄어든다. 외부 모달은 고정된 높이를 유지하고 콘텐츠가 많은 경우에만 내부 영역이 스크롤된다.

결과 모달은 다음 영역을 압축한다.

- 상하 카드 패딩
- 우승 캐릭터 크기와 주변 여백
- 피드백 문구 영역의 최소 높이와 여백
- 순위 항목의 높이, 간격, 캐릭터 크기
- 하단 버튼과 목록 사이 여백

다시 골라줘 모달은 캐릭터 더미 영역과 개별 이미지를 현재보다 약 20~25% 줄인다. 제목, 캐릭터, 버튼의 3단 그리드를 사용하고 버튼 영역이 항상 카드 안쪽 하단에 남도록 한다. `잠깐 쉴게` 버튼 아래에는 카드 안쪽 안전 여백을 확보한다. 최종 확인 상태의 우는 캐릭터에도 같은 축소 기준을 적용한다.

## 종료선

현재 종료선은 원본 텍스처를 1.5회 반복해 경계에서 같은 색 칸이 맞닿을 수 있다. 이를 제거하고 런타임 캔버스에 짝수 개 열과 2개 행의 체크 패턴을 직접 그린다. 각 칸은 행과 열의 합이 홀수인지에 따라 검정/흰색을 교차시키므로 가로 경계와 반복 이음새에서 같은 색이 연속되지 않는다.

생성된 캔버스 텍스처를 코스 전체 너비보다 약간 넓은 평면에 적용해 양옆 빈틈을 없앤다. 종료선 높이는 기존 비율과 비슷하게 유지하고 이미지 단순 확대는 사용하지 않는다.

## 검증

- `npm run build`
- `npm run build:ait`
- 짧은 모바일 뷰포트에서 홈 화면에 세로·가로 스크롤이 없는지 확인
- 캐릭터 확대와 이름 배지 하단 여백 확인
- 결과 모달과 다시 골라줘 모달의 외곽 높이가 같은지 확인
- 다시 골라줘 및 최종 확인 상태에서 하단 버튼이 잘리지 않는지 확인
- 참가자 2명과 4명 모두에서 모달 콘텐츠 접근 가능 여부 확인
- 종료선 모든 가로 칸이 검정/흰색으로 교차하며 양옆을 채우는지 확인
- 비게임 네비게이션 타입과 뒤로가기 흐름이 유지되는지 빌드 산출물 설정으로 확인

## 제외 범위

- 토스 네이티브 네비게이션 컴포넌트 자체의 높이 변경
- 홈 화면의 구성 요소 삭제 또는 스크롤 재도입
- 게임 물리, 음향, 테마, 참가자 입력 로직 변경
